# CryptoNinja 忍びの謎巡り

毎日ひとつ、忍者キャラと解く**大人のAIなぞとき旅**。40代からゆっくり遊べる脳トレPWA。

## 特徴

- **毎日変わる任務**: 日付シード×テンプレート10種で謎を端末内生成(オフライン可・APIキー不要・課金なし)
- **謎は10種類**: ずらし暗号 / 方角の暗号 / 地図なぞとき / 証言すいり / 違和感さがし / 記憶ミッション / 忍具えらび / 和文化クイズ(固定50問) / 数の謎 / 暦と月の謎
- **相棒キャラ3体**(CryptoNinja/CNP・CC0): 🐼リーリー(案内役) / 🐍オロチ(暗号と道) / 🐇ルナ(月と暦)。得意分野の謎で小判ボーナス
- **ヒント3段階**・制限時間なし・ペナルティなし・スタミナなし
- **旅日記**: クリアした日の記録が和風の日記として残る
- **里づくり**: ほうびの小判で飾りを買い、自分の忍びの里を育てる
- **蔵**: 巻物12巻・忍具12種・旅のしるしを収集
- **難易度3段階**(やさしい/ふつう/手ごたえあり)・文字サイズ3段階

## 安全・安心設計

- 自由チャットなし / 個人情報入力なし / 外部リンクなし / 広告なし / 課金なし
- エロ・グロ・血・過度なホラーなし。暴力表現は「煙玉で逃げる」程度

## 動かし方

- ローカル確認: `python -m http.server 8643 --directory shinobi-meguri` → http://localhost:8643
- 公開: `★ゲームを公開する.bat` をダブルクリック(GitHub Pagesへ)

## スマホへの登録

- iPhone: Safariで公開URLを開く → 共有 → **ホーム画面に追加**
- Android: Chromeで開く → メニュー(⋮) → **アプリをインストール**

## 構成

| ファイル | 役割 |
|---|---|
| `data.js` | キャラ・エリア・和文化クイズ50問・忍具・巻物・里の装飾 |
| `gen.js` | シード式の謎生成エンジン(テンプレート10種+3段階ヒント) |
| `game.js` | 画面と進行(任務/日記/里/蔵/設定) |
| `sw.js` / `manifest.webmanifest` | PWA(オフライン・ホーム画面登録) |

※ CryptoNinja/CNPキャラ名を使った個人試作。商用化・一般公開時は公式ガイドラインの確認必須。
