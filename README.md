# CryptoNinja 忍びの謎巡り

毎日ひとつ、忍者キャラと解く**大人のAIなぞとき旅**。40代からゆっくり遊べる脳トレPWA。

## 特徴

- **毎日変わる任務**: 日付シード×テンプレート10種で謎を端末内生成(オフライン可・APIキー不要・課金なし)
- **謎は10種類**: ずらし暗号 / 方角の暗号 / 地図なぞとき / 証言すいり / 違和感さがし / 記憶ミッション / 忍具えらび / 和文化クイズ(固定50問) / 数の謎 / 暦と月の謎
- **相棒キャラ3体**(CryptoNinja/CNP・CC0): 🐼リーリー(案内役) / 🐍オロチ(暗号と道) / 🐇ルナ(月と暦)。得意分野の謎で小判ボーナス
- **ヒント3段階**・制限時間なし・ペナルティなし・スタミナなし
- **旅日記**: クリアした日の記録が和風の日記として残る
- **里づくり**: ほうびの小判で飾りを買い、自分の忍びの里を育てる
- **蔵**: 巻物12巻・忍具12種・旅のしるしを収集
- **難易度3段階**(やさしい/ふつう/手ごたえあり)・文字サイズ3段階

## 安全・安心設計

- 自由チャットなし / 個人情報入力なし / 課金なし
- エロ・グロ・血・過度なホラーなし。暴力表現は「煙玉で逃げる」程度
- **謎を解いている最中の画面には広告を出さない**(選択肢ボタンの誤タップ防止)

## 広告について

運営費をまかなうため Google AdSense を掲載しています。設定と審査の手順は
[ADSENSE-SETUP.md](ADSENSE-SETUP.md) にまとめました。

`ads.js` の `ADS_CONFIG` に自分のIDを入れるまで、広告枠は自動的に非表示になります。

配置は次の4か所のみです。

| 枠 | 場所 |
|---|---|
| `home` | ホーム画面(「旅に出る」ボタンより下) |
| `result` | 任務クリア・腕試しクリアの結果画面 |
| `list` | 旅日記・蔵の一覧の下 |
| `article` | 読みものページの上下 |

出題中(`renderPuzzle`)と里の画面には出しません。
広告枠は `index.html` に静的に置いてあり、画面の再描画では作り直しません
(1枠あたり1ページロードにつき1リクエスト。自動リロードなし)。

## 読みもの・規約ページ

SPAはHTMLに文字がほとんど無く、クローラーからは白紙同然に見えます。
AdSenseの「有用性の低いコンテンツ」対策として、静的HTMLのページを追加しています。

| ページ | 内容 |
|---|---|
| `guide.html` | 遊び方と10種類の謎の解き方 |
| `wa-koyomi.html` | 旧暦・干支・月の満ち欠け・昔の時刻・年中行事 |
| `ninja-jiten.html` | 忍具12種の使い分けと忍びのことば |
| `about.html` | このゲームについて・運営者情報 |
| `privacy.html` | プライバシーポリシー(Cookie・広告・端末内保存) |
| `terms.html` | 利用規約 |
| `contact.html` | お問い合わせ |

## 動かし方

- ローカル確認: `python -m http.server 8643 --directory shinobi-meguri` → http://localhost:8643
- 公開: `★ゲームを公開する.bat` をダブルクリック(GitHub Pagesへ)

## スマホへの登録

- iPhone: Safariで公開URLを開く → 共有 → **ホーム画面に追加**
- Android: Chromeで開く → メニュー(⋮) → **アプリをインストール**

## 構成

| ファイル | 役割 |
|---|---|
| `data.js` | キャラ・エリア・和文化クイズ50問・忍具・巻物・里の装飾 |
| `gen.js` | シード式の謎生成エンジン(テンプレート10種+3段階ヒント) |
| `game.js` | 画面と進行(任務/日記/里/蔵/設定) |
| `ads.js` | 広告の設定・読み込み・枠の出し分け |
| `style.css` / `pages.css` | ゲーム本体 / 読みものページの体裁 |
| `sw.js` / `manifest.webmanifest` | PWA(オフライン・ホーム画面登録) |
| `robots.txt` / `sitemap.xml` | クローラー向け |

※ CryptoNinja/CNPキャラ名を使った個人試作。商用化・一般公開時は公式ガイドラインの確認必須。
